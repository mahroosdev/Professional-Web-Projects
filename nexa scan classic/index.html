Nexa Scan — QR & Barcode Studio

What is Nexa Scan? A modern web-based tool that supports generating and decoding multiple formats including QR Codes, UPC, EAN, Code 128, Code 39, Code 93, and more. Designed for retail, logistics, and general-purpose use — all processing runs directly in the browser, ensuring speed, privacy, and ease of use without any server dependency.

Privacy-first & instant: Every operation — QR generation, barcode encoding, and image decoding — happens in your browser. Nothing is transmitted. Your data stays yours.

Getting Started

  1. Generate: Pick a format (Qrix or Barix), enter data, customize appearance.
  2. Export: Download PNG, SVG, or copy to clipboard.
  3. Decode: Drag an image to the Decode tab — instant results.
  4. Use: All results save to local history for quick reference.
Tip Use high-contrast images for best decode results.

Sovereign performance.
Zero compromise.

Nexa Scan is engineered on the principle that a professional studio need not sacrifice speed for capability. Every operation — from generation to decoding — runs entirely within your browser. Nothing is ever transmitted, stored, or observed.

⚡
Instant Generation
QR codes and barcodes render to canvas in a single synchronous pass — no server round-trips, no waiting. Output is ready the moment you click Generate.
🌐
Fully Offline Capable
No telemetry. No analytics. No external API calls during generation or decode. All logic runs inside your browser using the Web Crypto API and native Canvas.
🧩
Minimal Dependencies
Only two micro-libraries are loaded: qrcodejs for QR matrix generation and jsQR for decode. Everything else is vanilla JS.
🎨
Canvas-First Rendering
All visual output is drawn directly onto an <canvas> element. This eliminates layout thrash from DOM manipulation and enables pixel-perfect PNG and SVG exports at any scale.
🔒
Local Cryptography
Image decoding is performed entirely client-side via pixel-row sampling. Your images never leave your device — privacy is structural, not a policy promise.
✦
5 Luxury Themes
Ivory, Obsidian, Slate, Parchment, and Emerald — each crafted for extended sessions with a refined typographic hierarchy and zero visual fatigue.
