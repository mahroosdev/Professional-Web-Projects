🎯 What is this?
🎨 About UltraThemeForge
UltraThemeForge is an AI-powered website mockup generator that creates fully working HTML/CSS/JS previews for 50 different types of websites. Each type gets 3 unique visual variants — Clean, Bold, and Dark — giving you 150 completely different mockup designs in total.

Powered by Google AI Studio (Gemini), every mockup is a real, functional HTML page — not a wireframe or template. You get actual code you can copy, study, and adapt for your own projects.
✅
Real working HTML/CSS/JS output
✅
Saved locally — works offline after generation
✅
Copy any mockup's full source code instantly
✅
Fullscreen preview with browser chrome UI
What's new (v1.0): Responsive previews, lazy-loading of previews, mobile sidebar & hamburger fix, improved API timeouts and error handling, in-app Gemini model selector (2.5 Flash / 2.5 Flash-Lite / 3.5 Flash) and per-model usage/credit tracker, safer localStorage parsing, and performance optimizations.

🔑 API Connection Guide
📋 Step-by-Step
How to Get Your API Key
1
Open Google AI Studio
Go to Google AI Studio and sign in with your Google account — no credit card needed for the free tier.
https://aistudio.google.com/apikey
2
Navigate to API Keys
Click "Get API key" — AI Studio shows your existing keys and lets you create new ones.
3
Create a New Key
Click "Create API key", pick (or auto-create) a project, and copy the key.
AIza... (your Google API key)
4
Paste Into the App
Select any type from the sidebar → paste your key in the API Setup banner → click Save Key. Done.
5
Start Generating!
Click "⚡ Generate All 3" on any type to create all 3 variants at once, or click individual placeholder cards.
🔒
Your API key is stored only in your browser's localStorage — it never leaves your device or gets sent anywhere except directly to Google AI Studio (Generative Language API) servers.

🔋 Offline Support
Works Offline After Generation
Once a mockup is generated, it's saved to your browser's localStorage as complete HTML. The app works fully offline for previewing, copying, and browsing all saved mockups — no internet needed.

Only generating new mockups requires an active internet connection to reach Google AI Studio (Gemini).
💾
localStorage stores up to ~5MB per domain. 150 full HTML mockups may approach this limit. If storage is full, older mockups may be cleared — export important ones as HTML files first.
🤖 How It Works
How the AI Generates Each Mockup
Each generation call sends a carefully crafted master prompt to Google AI Studio (Gemini) that includes three layers of instruction — ensuring every mockup is unique, realistic, and appropriate for its type:
📐
Master Prompt
Global quality rules: pixel-perfect UI, real content, no Lorem Ipsum, navbar + hero + sections + footer structure, Google Fonts required.
🌐
Type Context
Specific instructions for that website type — terminology, UI patterns, content sections, and layout logic appropriate for e.g. "E-commerce" vs "AI-Powered".
🎨
Variant Style
Visual personality rules — color palette, typography style, spacing approach, and aesthetic tone specific to Clean / Bold / Dark.
