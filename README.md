## 📒 Nexa Folio Ultra v1.0

An offline-first notes and task management application built as a Progressive Web App (PWA).

### Features — Nexa Folio Ultra v1.0

* Rich text note editor
* Task management with priorities and filters
* Five built-in themes
* Focus (Pomodoro) timer
* World clock with timezone support
* Installable PWA with offline functionality
* Local storage only (no server required)

---

### Features — Nexa Scan Classic v1.0

## 🛠️ Tech Stack

| Technology           | Purpose                                           |
| -------------------- | ------------------------------------------------- |
| HTML5                | Semantic structure and accessibility              |
| CSS3                 | Layout, animations, themes, and custom properties |
| JavaScript (Vanilla) | Application logic                                 |
